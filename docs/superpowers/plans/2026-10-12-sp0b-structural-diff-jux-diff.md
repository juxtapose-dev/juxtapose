# SP0 PR (b): Structural Diff, `jux diff`, Tier-0 Handoff and Multi-URL Snap — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn two structure sidecars plus a pixel diff into a deterministic tier-0 `StructuralVerdict` (what changed, by how much, whether it explains every changed pixel), ship it as `jux diff <a> <b>`, attach it to failing stories in `jux run`, lead the handoff prompt with it, and let one `jux snap` call capture several pages so `jux diff --prefix before after` can verdict all of them.

**Architecture:** `packages/core/src/diff/structural/` is a chain of small pure modules — `match` (per-parent LCS), `deltas` (one typed fact per change, masked elements geometry-only), `shift` (collapse a contiguous run of equal moves after an anchor into one `shift`), `coverage` (which pixel regions a delta explains), `classify` (classification + flags), `summary` (templated prose + delta prose) — composed by `diff/structural.ts` into the verdict with a stable key order and a signature. `diff/compare.ts` pairs two on-disk snaps (pixels via the existing `diffImages`, no browser). The CLI, `jux run` and the handoff only format what core returns. All fixtures are real Chromium captures of one corpus page, generated by a committed script, and the same corpus page drives the end-to-end mutation script in CI.

**Tech Stack:** TypeScript (ESM, Node 22), vitest, sharp + pixelmatch (already in core), Playwright Chromium for fixture generation and scripts only, pnpm workspaces.

**Spec:** `docs/specs/2026-10-12-sp0-structural-diff-agent-surface-design.md` — §3 (structural diff, verdict, flags incl. `below-fold`), §5 (`signature` only; `groups` is PR c), §6 (`jux diff`, multi-URL `snap`, `--prefix`, `jux run`, `jux handoff`), Verification 1, 2, 4, 5. Read it with this plan. PR (a) is squash-merged on main as `966f6e7` and this branch is rebased onto main `8efd520`; its code, not its plan, is the contract.

## Global Constraints

- Pass/fail stays the pixel hash. Nothing here changes a story's `status`. Structure explains, never decides.
- Green path unchanged: `structuralDiff` is called only inside the `status === 'fail'` branch of `judge()` in `packages/core/src/run/run.ts`, after `diffImages`. A green run never reads a sidecar (Verification 5).
- A missing sidecar on either side (capture failed, baseline predates sidecars, store without `getStructure`, corrupt gzip) yields a verdict carrying `no-baseline-structure` / `no-current-structure`, or no `structural` at all — never a throw. The manifest may hold a `structureHash` with no sidecar file; never trust the hash as proof of a file.
- Masked elements (`tag === 'masked'`) never produce `text`, `style` or `attr` deltas, only `added`/`removed`/`moved`/`resized`.
- Determinism: `JSON.stringify(verdict)` for the same inputs is byte-identical across processes — object literals built in one fixed key order, no `Map` iteration into output, no timestamps, no absolute paths from core, every list sorted by a documented key.
- Schema strings: `'juxtapose.verdict/v1'` (one verdict) and `'juxtapose.verdict-set/v1'` (`--prefix` output). Documented in README with one real example.
- Fixtures come from real Chromium output written by a committed script (`scripts/structural-corpus/*`, `scripts/capture-diff-fixtures.mjs`), never hand-written. A test may transform a real fixture (clone it 100×, blank a field) but never author one.
- Snap names stay path-safe: every name the CLI derives from user input goes through `snapName()` (`packages/cli/src/snap-name.ts`).
- CLI exit codes (owner decision, new commands only — `run`/`approve`/`check`/`handoff` are untouched; they migrate in PR H): **0** clean or identical, **1** changes found or needs review (a different verdict; a `--prefix` set with an unpaired page), **2** usage error (missing argument, unknown snap name, conflicting flags), **3** tool or environment failure (browser launch failed, a page could not be captured, an image that will not decode, a sidecar file present but undecodable, filesystem error, unexpected crash). `jux snap` is part of this unmerged stack and adopts the same codes: its per-page failures (unreachable host, non-2xx) move from 1 to 3 and `check-snap.mjs` is updated to pin them. A sidecar that is _absent_ is not a failure: it degrades to `no-baseline-structure`/`no-current-structure` and the verdict's own code applies. Every code is pinned by a test or an end-to-end check.
- Errors: every user-facing error says what happened and the next command to run (e.g. `jux diff: no snap named 'before' in <dir>. Run \`jux snap <url> --as before\` first.`).
- Help: `jux --help` gains a `diff` section and a 3-line before/edit/after example for both `diff` and multi-URL `snap`.
- Performance: `structuralDiff` on a 5,000-element pair runs under 50 ms (tests warm up once, take the best of 3, assert < 250 ms and print the measured number); multi-URL snap uses one browser, one context, one page; `jux diff` imports nothing from playwright (the CLI lazy-imports each command inside its `switch`; `check-diff.mjs` runs it with `NODE_OPTIONS=--import <probe.mjs>` that makes any `require`/`import` of `playwright` throw, plus `PLAYWRIGHT_BROWSERS_PATH=/nonexistent`) and launches no browser.
- Determinism of ordering: every comparator uses code-unit comparison (`a < b ? -1 : a > b ? 1 : 0`); `localeCompare` is never used.
- Size: tier-0 JSON ≤ 1,500 chars for every corpus operator; the corpus script asserts it and prints the distribution.
- Clean code: no dead options or unused flags; each module one responsibility; comments say why; typed throughout (no `any`, no untyped dicts where a named type fits).
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Run `pnpm format` before every commit; CI runs `prettier --check`.
- Spec refinements made here (call out in the PR):
  1. Two classifications added: `identical` (no changed pixels, no dimension change) and `attr-only` (only `attr` deltas, e.g. an image src swap). Both were implied by §6 / Verification 2 but absent from the §3 table.
  2. `render-drift` vs `unknown` when `structureHash` is equal: `unknown` when an unexplained region intersects a self-painting element (`canvas`, `video`, `img`, `iframe`, `object`, `embed`) on the current side, else `render-drift`. The spec's table puts `render-drift` first but Verification 2 expects a canvas redraw to be `unknown`; this rule satisfies both.
  3. Geometry is a consequence, not a cause: `reflow`/`geometry` apply only when there are no `text`/`style`/`attr` deltas. A padding change is `style-only (spacing)` with its `shift` still listed (the spec's own summary example), not `reflow`.
  4. Style deltas are reported where they originate: an inherited property that changed on an ancestor is one delta on the ancestor, not one per descendant.
  5. Shift anchor is the nearest preceding element with any non-geometry delta (added/removed/resized per spec, plus style/text/attr), so a margin change that moves everything below it collapses too.
  6. Added/removed deltas are emitted for the subtree root only; its descendants are neither matched nor listed.
  7. A second matching pass pairs leftover siblings by tag in order, so a button whose text changed (and so whose `role+name` key changed) reports `text` rather than `removed`+`added`.
  8. `no-current-structure` flag added beside `no-baseline-structure`: `jux diff` has no privileged side.
  9. `el` for an element with no role+name/id/testid/class is its `path` with the `html>body>` prefix and `:nth-of-type(1)` noise stripped.
  10. `jux diff --crops` lands in PR (c). Until then the flag exits 2 naming both image paths to open instead.
  11. Exit code 3 (tool/environment failure) for `snap` and `diff`, per the owner's decision; the spec's §6 "1 different or failed" is split into 1 (different) and 3 (failed). `jux snap`'s per-page failures move from 1 to 3 in the same stack; a rejected URL scheme (`file:`) is a bad argument and stays 2.
  12. The verdict's `escalate: { crops }` is renamed `escalate: { command }`: it holds the next command to run — `jux diff <a> <b> --crops` in snap mode, `jux handoff <id>` in run mode — because core does not know which CLI surface produced the verdict.
  13. Coverage is computed over changed-region area (a region is explained when it intersects a delta element's old or new rect), not per-pixel: the diff carries bounding boxes, and boxes are what the verdict reports back.

## Review Focus

1. **Two snapshots at different viewports or with `dimensionMismatch`** (user snapped `--viewport 390x844` then forgot). Expect `dimension-change`, no element deltas claimed as the cause, exit 1, summary names both sizes. Test: Task 3.
2. **A page over the 5,000-element cap on one side only** (list grew past the cap). Expect `structure-truncated`, deltas only for elements present on both sides, no spurious `removed` for the cut tail — those are reported as a count in the summary, not as deltas. Test: Task 3.
3. **A snap whose sidecar is missing on exactly one side**, including a corrupt gzip. Expect `unknown` + `no-baseline-structure` or `no-current-structure`, summary says to re-snap, exit 1, no throw. Test: Task 4 (`check-diff.mjs`) and Task 3 unit.
4. **`--prefix` sets that do not pair up** (`before-home`, `before-settings`, `after-home`). Expect the unpaired slug listed under `missing`, the paired page still verdicted, exit 1, message says which snap to take. Test: Task 6.
5. **Duplicate-looking siblings** (five identical `<li>` with no id/class, one removed in the middle). Expect one `removed`, four matched, no cascade of `text` deltas. Test: Task 1.

```ts
/** One changed fact between two structure snapshots. `el` is a short human
 *  label (`button[name="Save"]`, `div#row-1`, `div.card`, or a trimmed path). */
export type Delta =
  | { kind: 'text'; el: string; from: string; to: string }
  | { kind: 'style'; el: string; prop: string; from: string; to: string }
  | { kind: 'attr'; el: string; attr: 'src' | 'role' | 'name'; from: string; to: string }
  | { kind: 'added'; el: string; rect: StructureRect }
  | { kind: 'removed'; el: string; rect: StructureRect }
  | { kind: 'moved'; el: string; dx: number; dy: number }
  | { kind: 'resized'; el: string; dw: number; dh: number }
  /** ≥3 contiguous elements after `after` moved by the same (dx, dy). */
  | { kind: 'shift'; after: string; dx: number; dy: number; count: number };

export type Classification =
  | 'identical'
  | 'render-drift'
  | 'dimension-change'
  | 'element-added'
  | 'element-removed'
  | 'reflow'
  | 'geometry'
  | 'text-only'
  | 'style-only'
  | 'attr-only'
  | 'mixed'
  | 'unknown';

/** Sub-tags of `style-only`, so "colour tweak" and "spacing change" read
 *  differently at a glance. */
export type StyleTag = 'color' | 'typography' | 'spacing' | 'border' | 'effects';

export type Flag =
  | 'element-removed'
  | 'text-changed'
  | 'large-reflow'
  | 'unexplained-pixels'
  | 'structure-truncated'
  | 'no-baseline-structure'
  | 'no-current-structure'
  /** Either side's content is taller than the viewport: changes below the
   *  fold are invisible to both pixels and structure. */
  | 'below-fold';

/** Tier-0: what changed, in a few hundred characters, with whether it
 *  explains every changed pixel. The whole output of `jux diff`. */
export interface StructuralVerdict {
  schema: 'juxtapose.verdict/v1';
  classification: Classification;
  /** Empty unless classification is `style-only` or `mixed`. */
  styleTags: StyleTag[];
  /** Templated, deterministic, ≤ 300 chars. */
  summary: string;
  /** Capped at 20; `deltaCount` is the total. */
  deltas: Delta[];
  deltaCount: number;
  /** Fraction of changed-region area intersecting some delta's element. */
  coverage: number;
  /** ≥ 0.98 | ≥ 0.5 | below. */
  explained: 'full' | 'partial' | 'none';
  unexplainedRegions: ChangedRegion[];
  flags: Flag[];
  /** sha256 over the delta set with elements abstracted to role|tag, so two
   *  pages with the same change share one. */
  signature: string;
  /** The exact command for tier-3 pixels. */
  escalate: { command: string };
}
```

```js
const sameFields = (delta, want) =>
  Object.entries(want).every(([k, v]) => delta[k] === v);

/**
 * Every way a verdict can disagree with an operator's expectation, as
 * human-readable strings; empty means pass. The ONE checker: the unit test
 * (Task 3) and the end-to-end script (Task 7) both call it, so they cannot
 * drift apart.
 * @param {typeof OPERATORS[number]} op
 * @param {{ classification: string; styleTags: string[]; deltas: Array<Record<string, unknown>>; flags: string[]; explained: string }} v
 * @returns {string[]}
 */
export function checkVerdict(op, v) {
  const e = op.expect;
  const problems = [];
  if (v.classification !== e.classification)
    problems.push(`classification ${v.classification} ≠ ${e.classification}`);
  if (e.styleTags && JSON.stringify(v.styleTags) !== JSON.stringify(e.styleTags)) {
    problems.push(
      `styleTags ${JSON.stringify(v.styleTags)} ≠ ${JSON.stringify(e.styleTags)}`,
    );
  }
  if (e.delta && !v.deltas.some((d) => sameFields(d, e.delta)))
    problems.push(`missing delta ${JSON.stringify(e.delta)}`);
  for (const f of e.flags ?? [])
    if (!v.flags.includes(f)) problems.push(`missing flag ${f}`);
  if (e.noDeltas && v.deltas.length)
    problems.push(`expected no deltas, got ${v.deltas.length}`);
  if (e.shift && !v.deltas.some((d) => d.kind === 'shift'))
    problems.push('expected a shift delta');
  if (op.name !== 'noop' && op.name !== 'canvas' && v.explained !== 'full')
    problems.push(`explained ${v.explained}`);
  return problems;
}
```

```js
// Serves the corpus page on a random port: GET /op/<name> renders that
// operator's page; two logos exist so an `src` swap changes real pixels.
import { createServer } from 'node:http';
import { LOGO, pageHtml } from './page.mjs';

export function startCorpusServer() {
  return new Promise((resolve) => {
    const server = createServer((req, res) => {
      const url = new URL(req.url, 'http://localhost');
      if (url.pathname === '/logo-a.svg' || url.pathname === '/logo-b.svg') {
        res.writeHead(200, { 'content-type': 'image/svg+xml' });
        res.end(
          LOGO(url.pathname === '/logo-a.svg' ? 'rgb(37, 99, 235)' : 'rgb(220, 38, 38)'),
        );
        return;
      }
      // Operators live in the PATH, not the query: `jux snap` names a snap by
      // a slug of host + path and drops the query, so `/?op=a` and `/?op=b`
      // would collide on one file.
```

Create `packages/core/src/diff/structural/match.ts`:

```ts
// Which element on the baseline side is which element on the current side.
//
// Positional paths alone would report every sibling after an insertion as
// changed. Instead children are aligned per parent with an LCS over an
// identity key, recursing into matches, so an insertion is one `added` and the
// rest stay matched. LCS is per parent, so cost is Σ(children²) — small for
// real DOMs; a pathological flat parent falls back to in-order key pairing.

import type { StructureElement, StructureSnapshot } from '../../types.js';

export interface ElementMatch {
  /** [baseline index, current index], sorted by current index. */
  pairs: Array<[number, number]>;
  /** Current indices of unmatched subtree roots, ascending. */
  added: number[];
  /** Baseline indices of unmatched subtree roots, ascending. */
  removed: number[];
}

/** Above this many DP cells for one parent, pair greedily instead. */
const LCS_CELL_CAP = 250_000;

/** What makes an element "the same one" across captures: tag plus the most
 *  stable identity it carries. Masked stand-ins have only their tag. */
export function identityKey(el: StructureElement): string {
  if (el.id !== undefined) return `${el.tag}#${el.id}`;
  if (el.testId !== undefined) return `${el.tag}[${el.testId}]`;
  if (el.role && el.name) return `${el.tag}|${el.role}=${el.name}`;
  if (el.classes?.length) return `${el.tag}.${el.classes.join('.')}`;
  return el.tag;
}

export function matchElements(a: StructureSnapshot, b: StructureSnapshot): ElementMatch {
  const childrenA = childLists(a.elements);
  const childrenB = childLists(b.elements);
  const keyA = a.elements.map(identityKey);
  const keyB = b.elements.map(identityKey);
  const pairs: Array<[number, number]> = [];
  const added: number[] = [];
  const removed: number[] = [];

  const walk = (pa: number, pb: number): void => {
    const ca = childrenA.get(pa) ?? [];
    const cb = childrenB.get(pb) ?? [];
    const first = align(ca, cb, (i, j) => keyA[i] === keyB[j]);
    // A text edit changes a name-derived key, a toggled class changes a
    // class-derived one. Pair what is left by tag, in order, so those read as
    // `text`/`attr` deltas rather than removed + added.
    const second = align(
      first.leftA,
      first.leftB,
      (i, j) => a.elements[i].tag === b.elements[j].tag,
    );
    for (const [i, j] of [...first.matched, ...second.matched]) {
      pairs.push([i, j]);
      walk(i, j);
    }
    removed.push(...second.leftA);
    added.push(...second.leftB);
  };
  walk(-1, -1);

  pairs.sort((p, q) => p[1] - q[1]);
  added.sort((x, y) => x - y);
  removed.sort((x, y) => x - y);
  return { pairs, added, removed };
}

/** Children in document order, keyed by parent index; -1 is the root. */
function childLists(elements: StructureElement[]): Map<number, number[]> {
  const m = new Map<number, number[]>();
  elements.forEach((e, i) => {
    const p = e.parent ?? -1;
    const list = m.get(p);
    if (list) list.push(i);
    else m.set(p, [i]);
  });
  return m;
}

interface Alignment {
  matched: Array<[number, number]>;
  leftA: number[];
  leftB: number[];
}

/** Order-preserving alignment of two sibling lists under `same`. */
function align(
  ca: number[],
  cb: number[],
  same: (i: number, j: number) => boolean,
): Alignment {
  const matched =
    ca.length * cb.length > LCS_CELL_CAP ? greedy(ca, cb, same) : lcs(ca, cb, same);
  const usedA = new Set(matched.map(([i]) => i));
  const usedB = new Set(matched.map(([, j]) => j));
  return {
    matched,
    leftA: ca.filter((i) => !usedA.has(i)),
    leftB: cb.filter((j) => !usedB.has(j)),
  };
}

function lcs(
  ca: number[],
  cb: number[],
  same: (i: number, j: number) => boolean,
): Array<[number, number]> {
  const n = ca.length;
  const m = cb.length;
  // L[i][j] = LCS length of ca[i..] and cb[j..]
  const L: Uint32Array[] = Array.from({ length: n + 1 }, () => new Uint32Array(m + 1));
  for (let i = n - 1; i >= 0; i--) {
    for (let j = m - 1; j >= 0; j--) {
      L[i][j] = same(ca[i], cb[j])
        ? L[i + 1][j + 1] + 1
        : Math.max(L[i + 1][j], L[i][j + 1]);
    }
  }
  const out: Array<[number, number]> = [];
  let i = 0;
  let j = 0;
  while (i < n && j < m) {
    if (same(ca[i], cb[j])) {
      out.push([ca[i], cb[j]]);
      i++;
      j++;
    } else if (L[i + 1][j] >= L[i][j + 1]) i++;
    else j++;
  }
  return out;
}

/** In-order pairing: each a takes the first unused b after the last pairing
 *  that is `same`. Linear-ish, order-preserving, and good enough for a parent
 *  with thousands of children where an exact LCS would cost seconds. */
function greedy(
  ca: number[],
  cb: number[],
  same: (i: number, j: number) => boolean,
): Array<[number, number]> {
  const out: Array<[number, number]> = [];
  let j = 0;
  for (const i of ca) {
    let k = j;
    while (k < cb.length && !same(i, cb[k])) k++;
    if (k < cb.length) {
      out.push([i, cb[k]]);
      j = k + 1;
    }
  }
  return out;
}
```

Create `packages/core/src/diff/structural/deltas.ts`:

```ts
// One typed fact per changed thing between two matched snapshots.
//
// Style deltas are reported where they originate. Compact storage (see
// capture/structure.ts) stores an inherited property only where it differs
// from the parent, but a change on `main` still changes every descendant's
// effective colour — reporting it 40 times would bury the one fact that
// matters. So an inherited delta is emitted only where the element's own
// stored value changed, or where the parents' effective values already agree.

import {
  INHERITED_PROPS,
  STRUCTURE_PROPS,
  effectiveStyle,
  round,
} from '../../capture/structure.js';
import type { Delta, StructureRect, StructureSnapshot } from '../../types.js';
import { abstractLabel, label } from './label.js';
import type { ElementMatch } from './match.js';

export interface Fact {
  delta: Delta;
  /** Old and new rects of the element(s) this fact is about, for coverage. */
  rects: StructureRect[];
  /** `role|tag` of the element, for the signature. */
  abstract: string;
  /** Position in the current document; for `removed`, that of the preceding
   *  matched element. Keeps output order stable across runs. */
  order: number;
}

/** Within one position, which fact reads first. */
export const KIND_RANK: Record<Delta['kind'], number> = {
  removed: 0,
  added: 1,
  text: 2,
  attr: 3,
  style: 4,
  resized: 5,
  moved: 6,
  shift: 7,
};

const ATTRS = ['src', 'role', 'name'] as const;
const BORDER_COLOR = /^border-(top|right|bottom|left)-color$/;

export function computeFacts(
  a: StructureSnapshot,
  b: StructureSnapshot,
  match: ElementMatch,
): Fact[] {
  const facts: Fact[] = [];
  const aToB = new Map(match.pairs);

  for (const [i, j] of match.pairs) {
    const ea = a.elements[i];
    const eb = b.elements[j];
    const fact = (delta: Delta): Fact => ({
      delta,
      rects: [ea.rect, eb.rect],
      abstract: abstractLabel(eb),
      order: j,
    });
    // Text and attr deltas are labelled from the BASELINE side: a button's
    // label is its name, and its name is usually its text, so labelling from
    // the current side would read `button[name="Save changes"] text "Save"→
    // "Save changes"` — the label would spoil the delta. Everything else is
    // labelled from the current side, which is what the agent is looking at.
    const elA = label(ea);
    const el = label(eb);

    // Masked stand-ins carry no content by construction; anything that leaks
    // onto one must not surface as a delta either.
    if (ea.tag !== 'masked' && eb.tag !== 'masked') {
      const ta = ea.text ?? '';
      const tb = eb.text ?? '';
      if (ta !== tb) facts.push(fact({ kind: 'text', el: elA, from: ta, to: tb }));

      for (const attr of ATTRS) {
        const from = ea[attr] ?? '';
        const to = eb[attr] ?? '';
        if (from === to) continue;
        // A name that is just the text restates the text delta.
        if (attr === 'name' && from === ta && to === tb) continue;
        facts.push(fact({ kind: 'attr', el: elA, attr, from, to }));
      }

      for (const prop of STRUCTURE_PROPS) {
        // An unstored border colour resolves to currentColor, so a plain
        // `color` change would also report four phantom border-colour deltas
        // on every borderless element. No border, no border-colour fact.
        if (BORDER_COLOR.test(prop) && borderless(a, i, prop) && borderless(b, j, prop))
          continue;
        const from = effectiveStyle(a, i, prop);
        const to = effectiveStyle(b, j, prop);
        if (from === to) continue;
        if (INHERITED_PROPS.has(prop) && !originatesHere(a, b, i, j, aToB, prop))
          continue;
        facts.push(fact({ kind: 'style', el, prop, from, to }));
      }
    }

    const dw = round(eb.rect.w - ea.rect.w);
    const dh = round(eb.rect.h - ea.rect.h);
    if (dw !== 0 || dh !== 0) facts.push(fact({ kind: 'resized', el, dw, dh }));
    const dx = round(eb.rect.x - ea.rect.x);
    const dy = round(eb.rect.y - ea.rect.y);
    if (dx !== 0 || dy !== 0) facts.push(fact({ kind: 'moved', el, dx, dy }));
  }

  for (const j of match.added) {
    const e = b.elements[j];
    facts.push({
      delta: { kind: 'added', el: label(e), rect: e.rect },
      rects: [e.rect],
      abstract: abstractLabel(e),
      order: j,
    });
  }

  // A removed element has no current position; order it after the last
  // matched element that precedes it on the baseline side.
  const lastMatchedBefore = (i: number): number => {
    for (let k = i - 1; k >= 0; k--) {
      const j = aToB.get(k);
      if (j !== undefined) return j + 0.5;
    }
    return -0.5;
  };
  for (const i of match.removed) {
    const e = a.elements[i];
    facts.push({
      delta: { kind: 'removed', el: label(e), rect: e.rect },
      rects: [e.rect],
      abstract: abstractLabel(e),
      order: lastMatchedBefore(i),
    });
  }

  return sortFacts(facts);
}

/** That side of `border-<side>-color` has zero width on this element. */
function borderless(s: StructureSnapshot, i: number, colorProp: string): boolean {
  return effectiveStyle(s, i, colorProp.replace(/-color$/, '-width')) === '0px';
}

/** An inherited property changed on this element, not merely on an ancestor:
 *  either it stores its own value on a side, or its parents' effective values
 *  agree (so the difference starts here). */
function originatesHere(
  a: StructureSnapshot,
  b: StructureSnapshot,
  i: number,
  j: number,
  aToB: Map<number, number>,
  prop: string,
): boolean {
  const ea = a.elements[i];
  const eb = b.elements[j];
  if (ea.styles[prop] !== undefined || eb.styles[prop] !== undefined) return true;
  const pa = ea.parent;
  const pb = eb.parent;
  if (pa === null || pb === null) return true;
  // Parents unmatched: nothing above to blame, so report here.
  if (aToB.get(pa) !== pb) return true;
  return effectiveStyle(a, pa, prop) === effectiveStyle(b, pb, prop);
}

export function sortFacts(facts: Fact[]): Fact[] {
  return facts.sort(
    (x, y) =>
      x.order - y.order ||
      KIND_RANK[x.delta.kind] - KIND_RANK[y.delta.kind] ||
      compareCodeUnits(factKey(x.delta), factKey(y.delta)),
  );
}

function factKey(d: Delta): string {
  return d.kind === 'style' ? d.prop : d.kind === 'attr' ? d.attr : '';
}

/** Byte-identical output across machines needs a locale-free order;
 *  `localeCompare` is not one. */
export const compareCodeUnits = (a: string, b: string): number =>
  a < b ? -1 : a > b ? 1 : 0;
```

```ts
// "Everything below the banner moved down 14px because the banner grew 14px"
// is one fact, not forty. Collapse a run of ≥3 matched elements that moved by
// the same (dx, dy), contiguous in document order, into one `shift` anchored
// on the nearest preceding element that changed in some other way.
//
// The anchor set is wider than the spec's added/removed/resized: a margin or
// line-height change moves everything after it without resizing anything the
// LCS can see, and leaving those as 40 `moved` deltas defeats the purpose.

import type { Delta } from '../../types.js';
import { sortFacts, type Fact } from './deltas.js';

const MIN_RUN = 3;

export function synthesizeShifts(facts: Fact[]): Fact[] {
  const anchors = facts.filter(
    (f) => f.delta.kind !== 'moved' && f.delta.kind !== 'shift',
  );
  const moved = facts.filter((f) => f.delta.kind === 'moved');
  if (moved.length < MIN_RUN) return facts;

  // Group by displacement, keeping document order within a group.
  const groups = new Map<string, Fact[]>();
  for (const f of moved) {
    const d = f.delta as Extract<Delta, { kind: 'moved' }>;
    const key = `${d.dx},${d.dy}`;
    const g = groups.get(key);
    if (g) g.push(f);
    else groups.set(key, [f]);
  }

  const collapsed = new Set<Fact>();
  const shifts: Fact[] = [];
  // Deterministic: iterate groups by key, not by insertion.
  for (const key of [...groups.keys()].sort()) {
    const g = groups.get(key)!;
    if (g.length < MIN_RUN) continue;
    const first = g[0].order;
    const last = g[g.length - 1].order;
    // Contiguous: no element with a *different* non-zero move sits inside the
    // run. Unmoved elements inside it (sticky headers, absolutes) are fine.
    const intruder = moved.some(
      (f) => !g.includes(f) && f.order > first && f.order < last,
    );
    if (intruder) continue;
    const anchor = anchors.filter((f) => f.order < first).at(-1);
    if (!anchor) continue;
    const d = g[0].delta as Extract<Delta, { kind: 'moved' }>;
    for (const f of g) collapsed.add(f);
    shifts.push({
      delta: {
        kind: 'shift',
        after: 'el' in anchor.delta ? anchor.delta.el : anchor.delta.after,
        dx: d.dx,
        dy: d.dy,
        count: g.length,
      },
      rects: g.flatMap((f) => f.rects),
      abstract: anchor.abstract,
      order: anchor.order + 0.25,
    });
  }

  if (shifts.length === 0) return facts;
  return sortFacts([...facts.filter((f) => !collapsed.has(f)), ...shifts]);
}
```

```ts
// Does the structure explain the pixels? A changed region is explained when
// it intersects the old or new rect of some delta's element. Coverage is by
// region area: the diff carries bounding boxes, not per-pixel membership, and
// boxes are what an agent reads back.

import type { ChangedRegion, StructureRect } from '../../types.js';
import type { Fact } from './deltas.js';

export interface Coverage {
  coverage: number;
  explained: 'full' | 'partial' | 'none';
  unexplainedRegions: ChangedRegion[];
}

export function intersects(r: ChangedRegion, rect: StructureRect): boolean {
  return (
    r.x < rect.x + rect.w &&
    r.x + r.width > rect.x &&
    r.y < rect.y + rect.h &&
    r.y + r.height > rect.y
  );
}

export function computeCoverage(regions: ChangedRegion[], facts: Fact[]): Coverage {
  if (regions.length === 0)
    return { coverage: 1, explained: 'full', unexplainedRegions: [] };
  const rects = facts.flatMap((f) => f.rects);
  let total = 0;
  let explained = 0;
  const unexplainedRegions: ChangedRegion[] = [];
  for (const r of regions) {
    const area = r.width * r.height;
    total += area;
    if (rects.some((rect) => intersects(r, rect))) explained += area;
    else unexplainedRegions.push(r);
  }
  const coverage = total === 0 ? 1 : Math.round((explained / total) * 1000) / 1000;
  return {
    coverage,
    explained: coverage >= 0.98 ? 'full' : coverage >= 0.5 ? 'partial' : 'none',
    unexplainedRegions,
  };
}
```

```ts
// Classification and risk flags. First match wins, in an order that puts
// causes before consequences: a padding change that reflows the page is a
// spacing change with a shift in its deltas, not a "reflow" — the spec's own
// summary example says so.

import type {
  ChangedRegion,
  Classification,
  Delta,
  Flag,
  StructureSnapshot,
  StyleTag,
} from '../../types.js';
import type { Fact } from './deltas.js';
import { SELF_PAINTING } from './label.js';
import { intersects } from './coverage.js';

export interface ClassifyContext {
  baseline?: StructureSnapshot;
  current?: StructureSnapshot;
  facts: Fact[];
  explained: 'full' | 'partial' | 'none';
  unexplainedRegions: ChangedRegion[];
  pixels: { mismatchPixels: number; dimensionMismatch: boolean };
}

const TAG_ORDER: StyleTag[] = ['color', 'typography', 'spacing', 'border', 'effects'];

export function styleTagOf(prop: string): StyleTag {
  if (/^(padding|margin)-|^gap$/.test(prop)) return 'spacing';
  if (/^border-.*-(width|radius)$/.test(prop) || /^border-.*-color$/.test(prop))
    return 'border';
  if (/^(font-|line-height|letter-spacing|text-|content$)/.test(prop))
    return 'typography';
  if (/^(opacity|transform|box-shadow|z-index|stroke-width)$/.test(prop))
    return 'effects';
  return 'color'; // color, background-*, fill, stroke
}

export function classify(ctx: ClassifyContext): {
  classification: Classification;
  styleTags: StyleTag[];
} {
  const none: StyleTag[] = [];
  const { pixels, baseline, current, facts } = ctx;
  const identicalPixels = pixels.mismatchPixels === 0 && !pixels.dimensionMismatch;
  if (identicalPixels) return { classification: 'identical', styleTags: none };
  if (!baseline || !current) return { classification: 'unknown', styleTags: none };
  if (
    pixels.dimensionMismatch ||
    baseline.viewport.width !== current.viewport.width ||
    baseline.viewport.height !== current.viewport.height
  ) {
    return { classification: 'dimension-change', styleTags: none };
  }
  if (baseline.structureHash === current.structureHash) {
    const selfPainted = ctx.unexplainedRegions.some((r) =>
      current.elements.some((e) => SELF_PAINTING.has(e.tag) && intersects(r, e.rect)),
    );
    return { classification: selfPainted ? 'unknown' : 'render-drift', styleTags: none };
  }

  const kinds = new Set(facts.map((f) => f.delta.kind));
  if (kinds.has('removed')) return { classification: 'element-removed', styleTags: none };
  if (kinds.has('added')) return { classification: 'element-added', styleTags: none };

  const primary = (['text', 'style', 'attr'] as const).filter((k) => kinds.has(k));
  const styleTags = kinds.has('style')
    ? TAG_ORDER.filter((t) =>
        facts.some((f) => f.delta.kind === 'style' && styleTagOf(f.delta.prop) === t),
      )
    : none;
  if (primary.length > 1) return { classification: 'mixed', styleTags };
  if (primary[0] === 'text') return { classification: 'text-only', styleTags: none };
  if (primary[0] === 'style') return { classification: 'style-only', styleTags };
  if (primary[0] === 'attr') return { classification: 'attr-only', styleTags: none };
  if (kinds.has('shift')) return { classification: 'reflow', styleTags: none };
  if (kinds.has('moved') || kinds.has('resized'))
    return { classification: 'geometry', styleTags: none };
  return { classification: 'unknown', styleTags: none };
}

const LARGE_SHIFT_COUNT = 10;
const LARGE_SHIFT_PX = 50;

export function computeFlags(ctx: ClassifyContext): Flag[] {
  const flags: Flag[] = [];
  const { baseline, current, facts } = ctx;
  const has = (k: Delta['kind']) => facts.some((f) => f.delta.kind === k);
  if (has('removed')) flags.push('element-removed');
  if (has('text')) flags.push('text-changed');
  if (
    facts.some(
      (f) =>
        f.delta.kind === 'shift' &&
        (f.delta.count >= LARGE_SHIFT_COUNT || Math.abs(f.delta.dy) >= LARGE_SHIFT_PX),
    )
  ) {
    flags.push('large-reflow');
  }
  if (ctx.explained !== 'full') flags.push('unexplained-pixels');
  if (baseline?.truncated || current?.truncated) flags.push('structure-truncated');
  if (!baseline) flags.push('no-baseline-structure');
  if (!current) flags.push('no-current-structure');
  const belowFold = (s: StructureSnapshot | undefined) =>
    s !== undefined && s.contentHeight > s.viewport.height;
  if (belowFold(baseline) || belowFold(current)) flags.push('below-fold');
  return flags;
}
```

```ts
// Deterministic prose. No model, no adjectives: the classification, the first
// few deltas, and whether the pixels are accounted for. Hard cap 300 chars.

import type {
  Classification,
  Delta,
  Flag,
  StructureSnapshot,
  StyleTag,
} from '../../types.js';

export const MAX_SUMMARY = 300;
const LEAD_DELTAS = 3;

export function describeDelta(d: Delta): string {
  switch (d.kind) {
    case 'text':
      return `${d.el} text "${trim(d.from)}"→"${trim(d.to)}"`;
    case 'style':
      return `${d.el} ${d.prop} ${d.from}→${d.to}`;
    case 'attr':
      return `${d.el} ${d.attr} ${d.from}→${d.to}`;
    case 'added':
      return `added ${d.el} (${d.rect.w}×${d.rect.h} at ${d.rect.x},${d.rect.y})`;
    case 'removed':
      return `removed ${d.el} (${d.rect.w}×${d.rect.h} at ${d.rect.x},${d.rect.y})`;
    case 'moved':
      return `${d.el} moved ${signed(d.dx)},${signed(d.dy)}px`;
    case 'resized':
      return `${d.el} resized ${signed(d.dw)}×${signed(d.dh)}px`;
    case 'shift':
      return `${d.count} elements after ${d.after} shifted ${signed(d.dx)},${signed(d.dy)}px`;
  }
}

export interface SummaryArgs {
  classification: Classification;
  styleTags: StyleTag[];
  deltas: Delta[];
  deltaCount: number;
  regionCount: number;
  explained: 'full' | 'partial' | 'none';
  flags: Flag[];
  baseline?: StructureSnapshot;
  current?: StructureSnapshot;
}

export function buildSummary(a: SummaryArgs): string {
  const head =
    a.styleTags.length > 0
      ? `${a.classification} (${a.styleTags.join(', ')})`
      : a.classification;
  const parts: string[] = [];

  if (a.classification === 'identical') {
    parts.push('identical: no changed pixels');
  } else if (
    a.flags.includes('no-baseline-structure') ||
    a.flags.includes('no-current-structure')
  ) {
    const side = a.flags.includes('no-baseline-structure') ? 'baseline' : 'current';
    parts.push(
      `${head}: no ${side} structure, so nothing explains the pixels; re-snap (or re-approve) with structure capture enabled`,
    );
  } else if (a.classification === 'dimension-change' && a.baseline && a.current) {
    parts.push(
      `${head}: ${size(a.baseline)} → ${size(a.current)}; compare at one viewport`,
    );
  } else if (a.classification === 'render-drift') {
    parts.push(`${head}: structure and styles identical, pixels differ`);
  } else if (a.deltas.length === 0) {
    parts.push(`${head}: no structural change found`);
  } else {
    const lead = a.deltas.slice(0, LEAD_DELTAS).map(describeDelta).join('; ');
    const more =
      a.deltaCount > LEAD_DELTAS ? ` (+${a.deltaCount - LEAD_DELTAS} more)` : '';
    parts.push(`${head}: ${lead}${more}`);
  }

  if (a.classification !== 'identical') {
    parts.push(
      `${a.regionCount} region${a.regionCount === 1 ? '' : 's'}, ${
        a.explained === 'full' ? 'fully' : a.explained === 'partial' ? 'partly' : 'not'
      } explained`,
    );
  }
  const trunc = [a.baseline, a.current].find((s) => s?.truncated)?.truncated;
  if (trunc) parts.push(`structure truncated (${trunc.kept}/${trunc.total} elements)`);

  const out = parts.join('. ') + '.';
  return out.length <= MAX_SUMMARY ? out : out.slice(0, MAX_SUMMARY - 1) + '…';
}

const size = (s: StructureSnapshot) => `${s.viewport.width}×${s.viewport.height}`;
const signed = (n: number) => (n > 0 ? `+${n}` : `${n}`);
const trim = (s: string) => (s.length > 40 ? s.slice(0, 39) + '…' : s);
```

```ts
// Structural diff → tier-0 verdict. Pure, no browser, no I/O.
//
// Composition: match → facts → shifts → coverage → classify → summary, then a
// signature over the abstracted facts. Every list is sorted by a documented
// key and the result is built as one literal, so the same inputs always
// serialize to the same bytes (the CLI promises that in its JSON contract).

import { createHash } from 'node:crypto';
import type { DiffOutput } from './diff.js';
import type { Delta, StructureSnapshot, StructuralVerdict } from '../types.js';
import { classify, computeFlags, type ClassifyContext } from './structural/classify.js';
import { computeCoverage } from './structural/coverage.js';
import { computeFacts, type Fact } from './structural/deltas.js';
import { matchElements } from './structural/match.js';
import { synthesizeShifts } from './structural/shift.js';
import { buildSummary } from './structural/summary.js';

export interface StructuralDiffInput {
  baseline?: StructureSnapshot;
  current?: StructureSnapshot;
  pixels: Pick<DiffOutput, 'mismatchPixels' | 'changedRegions' | 'dimensionMismatch'>;
  /** The exact tier-3 command; core does not know how the CLI is spelled. */
  escalate: { command: string };
}

export const MAX_DELTAS = 20;

export function structuralDiff(input: StructuralDiffInput): StructuralVerdict {
  const { baseline, current, pixels } = input;
  const comparable =
    baseline !== undefined &&
    current !== undefined &&
    !pixels.dimensionMismatch &&
    baseline.viewport.width === current.viewport.width &&
    baseline.viewport.height === current.viewport.height;

  // With a truncated side, the elements past the cap exist but were not
  // recorded; reporting them as removed would be a lie the summary already
  // tells more honestly as a count.
  const facts: Fact[] = comparable
    ? synthesizeShifts(
        computeFacts(baseline, current, matchElements(baseline, current)).filter(
          (f) =>
            !(f.delta.kind === 'removed' && current.truncated) &&
            !(f.delta.kind === 'added' && baseline.truncated),
        ),
      )
    : [];

  const cov = computeCoverage(pixels.changedRegions, facts);
  const ctx: ClassifyContext = {
    baseline,
    current,
    facts,
    explained: cov.explained,
    unexplainedRegions: cov.unexplainedRegions,
    pixels: {
      mismatchPixels: pixels.mismatchPixels,
      dimensionMismatch: pixels.dimensionMismatch,
    },
  };
  const { classification, styleTags } = classify(ctx);
  const flags = computeFlags(ctx);
  const deltas: Delta[] = facts.slice(0, MAX_DELTAS).map((f) => f.delta);

  return {
    schema: 'juxtapose.verdict/v1',
    classification,
    styleTags,
    summary: buildSummary({
      classification,
      styleTags,
      deltas,
      deltaCount: facts.length,
      regionCount: pixels.changedRegions.length,
      explained: cov.explained,
      flags,
      baseline,
      current,
    }),
    deltas,
    deltaCount: facts.length,
    coverage: cov.coverage,
    explained: cov.explained,
    unexplainedRegions: cov.unexplainedRegions,
    flags,
    signature: signature(facts),
    escalate: { command: input.escalate.command },
  };
}

/** sha256 of the facts with each element reduced to role|tag and the values
 *  kept: "every button background #2563eb→#1d4ed8" hashes the same on any
 *  page that made that change. Sorted so order of discovery cannot leak in. */
function signature(facts: Fact[]): string {
  const items = facts
    .map((f) => {
      const d = f.delta;
      const rest =
        d.kind === 'text' || d.kind === 'style' || d.kind === 'attr'
          ? [
              d.kind === 'style' ? d.prop : d.kind === 'attr' ? d.attr : 'text',
              d.from,
              d.to,
            ]
          : d.kind === 'moved'
            ? ['moved', d.dx, d.dy]
            : d.kind === 'resized'
              ? ['resized', d.dw, d.dh]
              : d.kind === 'shift'
                ? ['shift', d.dx, d.dy, d.count]
                : [d.kind];
      return JSON.stringify([f.abstract, ...rest]);
    })
    .sort();
  return createHash('sha256').update(items.join('\n')).digest('hex');
}
```

```ts
} from '@juxtapose/core';
import { EXIT } from '../exit-codes.js';
import { snapName } from '../snap-name.js';

export interface DiffFlags {
  json?: boolean;
  project?: string;
  crops?: boolean;
}

export function snapsDir(project?: string): string {
  return path.join(path.resolve(project ?? process.cwd()), '.juxtapose', 'snaps');
}

export type ReadSnap =
  | { kind: 'ok'; side: SnapSide }
  | { kind: 'missing'; image: string }
  | { kind: 'corrupt'; file: string; error: string };

/** A snap by name (or by `.webp` path), with its sidecar. An absent sidecar
 *  is fine — the verdict degrades and says so. A sidecar that exists and will
 *  not decode is a tool failure: it is not something the agent can reason
 *  around, so it is reported as one rather than silently dropped. */
export async function readSnap(dir: string, ref: string): Promise<ReadSnap> {
  const image = ref.endsWith('.webp')
    ? path.resolve(ref)
    : path.join(dir, `${snapName(ref, ref)}.webp`);
  const bytes = await readFile(image).catch(() => null);
  if (!bytes) return { kind: 'missing', image };
  const sidecar = image.replace(/\.webp$/, '.structure.json.gz');
  const gz = await readFile(sidecar).catch(() => null);
  if (!gz) return { kind: 'ok', side: { image: bytes } };
  try {
    return { kind: 'ok', side: { image: bytes, structure: decodeStructure(gz) } };
  } catch (err) {
    return { kind: 'corrupt', file: sidecar, error: (err as Error).message };
  }
}

export function formatVerdict(v: StructuralVerdict): string {
  const lines = [v.summary];
  for (const d of v.deltas) lines.push(`  - ${describeDelta(d)}`);
  if (v.deltaCount > v.deltas.length)
    lines.push(`  …and ${v.deltaCount - v.deltas.length} more`);
  if (v.flags.length) lines.push(`flags: ${v.flags.join(', ')}`);
  if (v.classification !== 'identical') lines.push(`pixels: ${v.escalate.command}`);
  return lines.join('\n') + '\n';
}

export async function diffCommand(
  a: string | undefined,
  b: string | undefined,
  flags: DiffFlags,
): Promise<number> {
  if (!a || !b) {
    process.stderr.write(
      'jux diff: needs two snap names, e.g. `jux diff before after`. Take them with `jux snap <url> --as before` and `--as after`.\n',
    );
    return EXIT.usage;
  }
  if (flags.crops) {
    // Tier-3 crops land in a later release; until then name the pixels to open.
    const dir = snapsDir(flags.project);
    process.stderr.write(
      `jux diff: --crops is not available in this version; open the images instead:\n  ${path.join(dir, `${snapName(a, a)}.webp`)}\n  ${path.join(dir, `${snapName(b, b)}.webp`)}\n`,
    );
    return EXIT.usage;
  }
  try {
    return await diffTwo(a, b, flags);
  } catch (err) {
    // sharp failing to decode a .webp, or anything else unforeseen: a tool
    // failure, distinct from "different" so a script never approves on it.
    process.stderr.write(
      `jux diff: failed: ${(err as Error).message}. Re-take both snaps with \`jux snap <url> --as ${a}\` / \`--as ${b}\` and retry.\n`,
    );
    return EXIT.failure;
  }
}

/** Resolve both sides or explain which one is unusable and how to fix it. */
async function loadSides(
  dir: string,
  a: string,
  b: string,
): Promise<{ sides: [SnapSide, SnapSide] } | { code: number }> {
  const [ra, rb] = await Promise.all([readSnap(dir, a), readSnap(dir, b)]);
  for (const [ref, r] of [
    [a, ra],
    [b, rb],
  ] as const) {
    if (r.kind === 'missing') {
      process.stderr.write(
        `jux diff: no snap named '${ref}' in ${dir}. Run \`jux snap <url> --as ${ref}\` first.\n`,
      );
      return { code: EXIT.usage };
    }
    if (r.kind === 'corrupt') {
      process.stderr.write(
        `jux diff: cannot read ${r.file} (${r.error}). Delete it or re-take the snap with \`jux snap <url> --as ${ref}\`.\n`,
      );
      return { code: EXIT.failure };
    }
  }
  return { sides: [(ra as { side: SnapSide }).side, (rb as { side: SnapSide }).side] };
}

async function diffTwo(a: string, b: string, flags: DiffFlags): Promise<number> {
  const dir = snapsDir(flags.project);
  const loaded = await loadSides(dir, a, b);
  if ('code' in loaded) return loaded.code;
  const [sa, sb] = loaded.sides;
  const { verdict } = await compareSnaps(sa, sb, {
    command: `jux diff ${a} ${b} --crops`,
  });
  process.stdout.write(
    flags.json ? JSON.stringify(verdict) + '\n' : formatVerdict(verdict),
  );
  return verdict.classification === 'identical' ? EXIT.clean : EXIT.review;
}
```

```ts
  const browser = await chromium.launch(deterministicLaunchOptions());

      } catch (err) {
        pages.push({ url, status, error: (err as Error).message });
      }
```

```ts
    // 0 passes the pattern but Playwright rejects it, which surfaced as exit 1
    // "could not capture" for what is a usage error.
    if (!m || Number(m[1]) === 0 || Number(m[2]) === 0) {
      process.stderr.write(
        `jux snap: --viewport must be WxH, both above 0, got '${flags.viewport}'\n`,

      return EXIT.usage;

  // error, and names derive from host + path, so two urls differing only by
  // query would silently overwrite each other.

  for (const url of urls) {
    if (!/^https?:\/\//i.test(url)) {
      process.stderr.write(
        `jux snap: '${url}' is not an http(s) url; snap a served page, e.g. http://localhost:5173/\n`,
      );
      return EXIT.usage;

    const name = nameOf(url);
    const prior = seen.get(name);
    if (prior) {
      process.stderr.write(
        `jux snap: '${url}' and '${prior}' would both be saved as '${name}'. Give them distinct paths, or snap them separately with --as <name>.\n`,
      );
      return EXIT.usage;

    seen.set(name, url);

  try {
    captured = await snapPages({
```

```ts
export interface PrefixPairing {
  pairs: Array<{ slug: string; a: string; b: string }>;
  missing: Array<{ slug: string; have: string; want: string }>;

/** Pair `<a>-<slug>.webp` with `<b>-<slug>.webp`, sorted by slug. */
export function pairByPrefix(files: string[], a: string, b: string): PrefixPairing {
  const slugs = (p: string) =>
    new Set(
      files
        .filter((f) => f.startsWith(`${p}-`) && f.endsWith('.webp'))
        .map((f) => f.slice(p.length + 1, -'.webp'.length)),
    );
  const sa = slugs(a);
  const sb = slugs(b);
  const all = [...new Set([...sa, ...sb])].sort();
  const pairs: PrefixPairing['pairs'] = [];
  const missing: PrefixPairing['missing'] = [];
  for (const slug of all) {
    if (sa.has(slug) && sb.has(slug))
      pairs.push({ slug, a: `${a}-${slug}`, b: `${b}-${slug}` });
    else if (sa.has(slug))
      missing.push({ slug, have: `${a}-${slug}`, want: `${b}-${slug}` });
    else missing.push({ slug, have: `${b}-${slug}`, want: `${a}-${slug}` });
  }
  return { pairs, missing };
}
```

```js
// The mutation corpus, end to end through the CLI: snap the base page, snap
// each mutated page (one browser launch for all of them), diff every one
// against the base, and assert the classification and delta each operator
// must produce. Also the tier-0 size budget: every verdict ≤ 1,500 chars,
// distribution printed. Seed for the row-4 benchmark.
// Run after `pnpm build`: node scripts/structural-corpus.mjs
import { execFile } from 'node:child_process';
import { promisify } from 'node:util';
import { mkdtempSync, rmSync } from 'node:fs';
import { tmpdir } from 'node:os';
import path from 'node:path';
import { OPERATORS, checkVerdict } from './structural-corpus/page.mjs';
import { startCorpusServer } from './structural-corpus/server.mjs';

const exec = promisify(execFile);
const cli = path.resolve(import.meta.dirname, '../packages/cli/dist/index.js');
// The CLI's own slug function, so this script cannot drift from how `jux
// snap` names files.
const { snapName } = await import(
  path.resolve(import.meta.dirname, '../packages/cli/dist/snap-name.js')
);
const project = mkdtempSync(path.join(tmpdir(), 'jux-corpus-'));
const server = await startCorpusServer();
const BUDGET = 1500;
let failed = 0;
const check = (ok, msg) => {
  console.log(`${ok ? 'ok  ' : 'FAIL'} ${msg}`);
  if (!ok) failed++;
};
const jux = async (args) => {
  try {
    return (
      await exec('node', [cli, ...args, '--project', project, '--json'], {
        encoding: 'utf8',
      })
    ).stdout;
  } catch (e) {
    return e.stdout;
  }
};

// Every variant in one launch: `base` is the noop page under its own name.
await jux(['snap', `${server.url}/op/noop`, '--as', 'base']);
await jux([
  'snap',
  ...OPERATORS.map((o) => `${server.url}/op/${o.name}`),
  '--as-prefix',
  'op',
]);

const lengths = [];
for (const op of OPERATORS) {
  const out = await jux([
    'diff',
    'base',
    `op-${snapName(`${server.url}/op/${op.name}`)}`,
  ]);
  const v = JSON.parse(out);
  const problems = checkVerdict(op, v);
  const len = out.trim().length;
  lengths.push([op.name, len]);
  if (len > BUDGET) problems.push(`${len} chars > ${BUDGET}`);
  check(
    problems.length === 0,
    `${op.name.padEnd(15)} ${v.classification.padEnd(16)} ${String(len).padStart(5)} chars ${problems.join('; ')}`,
  );
}

const sorted = lengths.map(([, l]) => l).sort((a, b) => a - b);
console.log(
  `tier-0 JSON chars: min ${sorted[0]}  median ${sorted[Math.floor(sorted.length / 2)]}  max ${sorted.at(-1)}  (budget ${BUDGET}; ≈${Math.round(sorted.at(-1) / 4)} tokens max)`,
);

server.close();
rmSync(project, { recursive: true, force: true });
process.exit(failed ? 1 : 0);
```
